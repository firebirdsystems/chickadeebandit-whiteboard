# Whiteboard

A [Chickadee Bandit](https://chickadeebandit.com/app-library/whiteboard) app.

A shared canvas for the whole household. Draw together in real time — strokes sync instantly across all devices.

## Features

- Real-time collaborative drawing.
- Instant sync across devices.
- Anyone can clear the canvas.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-whiteboard/releases/latest/download/bundle.json
```
